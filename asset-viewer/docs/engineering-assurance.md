# SchemeWorks engineering assurance prototype

Reference baseline: NR/L2/RSE/02009 Issue 8 (4 March 2023). Verify applicability and controlled issue with project engineering management. This is not an approved process, compliance certification or official F-form implementation.

Project registers: TQ and RFI (13), variations (12), interdisciplinary check and review (15.3–15.4), engineering deliverables (15.1/15.7), appointments (10.1), hazards (5.2.4), technical changes (14), ECC and ECMP preparation (16 and 11.2). Fields are original draft aids; they are not an exhaustive clause checklist. No standard PDF or official form is embedded. Document templates are reusable project-scoped plain text using placeholders. Exports are escaped HTML working drafts (print to PDF) and CSV. Record status is administrative and does not constitute appointment, variation approval, technical approval, acceptance, instruction, AFC or ECC. Future work: authorised native templates, typed field mapping, revision-controlled evidence, sign-off, role-specific permissions, audit trail, scheme/asset/deliverable links, and review workflows. Modules /01 and /02 and the applicable controlled F-forms need to be reviewed first.

Interactive drawings: selected source-ink region is rendered as a blue mask above the immutable original PDF. Engineer can define a region by clicking two corners; symbol candidates inherit matcher bounds. The mask includes all dark/coloured ink in the rectangle, not semantic vector objects, and can include unrelated lines or text. Unbound markers retain circles. Move circles in circle mode; this clears the region, which must be rebound. Shared saves preserve region coordinates in the current revision-specific draft. Not a canonical asset model.

Validation plan: test highlight placement, visual alignment while zooming/panning, saved reload, original mode, read-only access, manually defined and matched regions, text template substitution and escaping, register CSV export, project isolation, simultaneous edits. Use approved test data only.
